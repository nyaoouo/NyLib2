# Stubs

[Index](index.md) · Code: `nylib/ue/stubs.py`

`.pyi` stubs give your editor completion and type checks for a game's classes, structs, enums and UFunctions. They are for the editor only; scripts never import them at run time.

## Write them

```python
from nylib.ue.stubs import write_stubs

report = write_stubs(r'ue_dumps\TRIANGLE_STRATEGY\20261002-024137', r'typings\ts')   # a snapshot folder
print(report.files, report.types, report.modules['/Script/Engine'])                # ... Script/Engine.pyi
```

The source can also be a loaded `Snapshot` or a session: `ue.write_stubs(r'typings\ts')`. A session attached to a snapshot writes that snapshot's stubs (no game access); a live session reads every type from the game, which is as slow as a dump. Write them again after a game update.

## Where to put them

- The last folder name is the package your scripts import from (`ts` above). It must be a valid Python name that hides no module (`nylib`, standard-library names).
- Put it in `typings/` at the root of your workspace. VS Code (Pylance) reads stubs from `typings` by default (`python.analysis.stubPath`); in PyCharm, mark `typings` as a source root.
- One module per UE package: `/Script/Engine` is `ts/Script/Engine.pyi`, `/Game/...` and `/Engine/...` packages are under `ts/Game/` and `ts/Engine/`. Container types (`TArray`, `TMap`, `TSet`, `FName`, ...) are in `ts/__init__.pyi`.
- A run replaces only the files it generated (they start with a `generated by nylib.ue ... do not edit` line) and removes its stale ones; other files stay. Do not point it inside another stub folder: a run into `typings/pal/Script` would remove `pal`'s modules there.
- A script outside this repository's workspace also needs the repository in `python.analysis.extraPaths` (or nylib installed with `pip install -e . --config-settings editable_mode=compat`), because the type checker cannot follow the default editable install.

## Use them

```python
# ue is a session (see runtime.md)
import typing
from typing import TYPE_CHECKING

if TYPE_CHECKING:                                   # editor only; nothing is imported at run time
    from ts.Script.Engine import APlayerController


def run(pc: 'APlayerController') -> None:           # an annotated parameter is typed
    print(pc.Pawn)


pc = typing.cast('APlayerController', ue.local_player_controller())
```

The session's lookups (`find`, `cdo`, `world`, `local_player_controller`, `component`, `objects_of`, `search`) return the base object type, so a type checker needs `typing.cast` or an annotated parameter to know the class.
A checker warns that the stub modules have no source (`reportMissingModuleSource`); that is expected.
