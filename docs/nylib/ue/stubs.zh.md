# Stubs

[索引](index.md) · 代码：`nylib/ue/stubs.py`

`.pyi` stub 文件为编辑器提供游戏的类、结构体、枚举和 UFunction 的补全和类型检查。它们只用于编辑器；脚本在运行时从不导入它们。

<!-- dt:section id="write-them-0" hash="23e85a26e085" -->
## 写出它们

```python
from nylib.ue.stubs import write_stubs

report = write_stubs(r'ue_dumps\TRIANGLE_STRATEGY\20261002-024137', r'typings\ts')   # a snapshot folder
print(report.files, report.types, report.modules['/Script/Engine'])                # ... Script/Engine.pyi
```

源也可以是已加载的 `Snapshot` 或一个 session：`ue.write_stubs(r'typings\ts')`。附加到快照的 session 会写出该快照的 stub（不访问游戏）；一个运行中的 session 会从游戏中读取每个类型，速度和转储一样慢。在游戏更新后重新写出它们。

<!-- dt:section id="where-to-put-them-0" hash="18e01fec4b4c" -->
## 放在哪里

- 最后一个文件夹名就是你的脚本要导入的包名（上面的 `ts`）。它必须是一个有效的 Python 名称，且不能遮蔽任何模块（`nylib`、标准库名称）。
- 把它放在工作区根目录的 `typings/` 下。VS Code（Pylance）默认从 `typings` 读取 stub（`python.analysis.stubPath`）；在 PyCharm 中，把 `typings` 标记为源代码根目录。
- 每个 UE 包对应一个模块：`/Script/Engine` 对应 `ts/Script/Engine.pyi`，`/Game/...` 和 `/Engine/...` 包位于 `ts/Game/` 和 `ts/Engine/` 下。容器类型（`TArray`、`TMap`、`TSet`、`FName` 等）在 `ts/__init__.pyi` 中。
- 一次运行只会替换它自己生成的文件（这些文件以一行 `generated by nylib.ue ... do not edit` 开头）并移除其中过期的文件；其他文件保持不变。不要把它指向另一个 stub 文件夹内部：运行到 `typings/pal/Script` 会删除 `pal` 在那里的模块。
- 本仓库工作区之外的脚本还需要把本仓库加入 `python.analysis.extraPaths`（或以 `pip install -e . --config-settings editable_mode=compat` 安装 nylib），因为类型检查器无法跟踪默认的可编辑安装。

<!-- dt:section id="use-them-0" hash="68ec38d0990e" -->
## 使用它们

```python
# ue is a session (see runtime.md)
import typing
from typing import TYPE_CHECKING

if TYPE_CHECKING:                                   # editor only; nothing is imported at run time
    from ts.Script.Engine import APlayerController


def run(pc: 'APlayerController') -> None:           # an annotated parameter is typed
    print(pc.Pawn)


pc = typing.cast('APlayerController', ue.local_player_controller())
```

session 的查找方法（`find`、`cdo`、`world`、`local_player_controller`、`component`、`objects_of`、`search`）返回的是基础对象类型，所以类型检查器需要 `typing.cast` 或带类型标注的参数才能知道具体的类。
检查器会警告 stub 模块没有源码（`reportMissingModuleSource`）；这是预期行为。
